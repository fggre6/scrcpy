# 按键映射可视化编辑器

在浏览器里对着手机画面拖拽布点，自动生成 scrcpy 映射模板 JSON。

打开方式：直接双击 `index.html`（Chrome / Edge 均可，离线、无依赖、不需要构建）。
首次打开会放三个示例组件（J / Up / 视角），点工具栏「清空」即可从空白开始。

## 用起来

1. **放背景图**（可选但强烈建议）：投屏里按 `Ctrl+S` 截一张游戏画面，或
   `adb exec-out screencap -p > shot.png`，然后点工具栏「背景图」，
   也可以直接把图片拖进画面 / `Ctrl+V` 粘贴。
2. **从左侧组件库拖一个组件到画面上**。组件落在哪里，就映射到哪里；
   组件上显示的名字就是它绑定的按键（放下后光标已在按键输入框里，直接改）。
3. **微调**：拖动组件移动位置（按住 `Shift` 吸附 5% 网格）；方向键微调
   （`Shift` 步长更大）；右侧属性面板改模式、灵敏度、位移、依赖条件等。
   画面太小看不清时：**滚轮缩放**（以指针为中心），工具栏 `−` / `＋` /
   「适应」，或 `Ctrl+=` / `Ctrl+-` / `Ctrl+0`；放大后按住**空格**拖动或
   用鼠标中键拖动平移。缩放只改变画面尺寸，组件、圆点、滑动终点都跟着
   背景一起放大缩小，坐标仍是归一化的，拖动、吸附、导出都不受影响。
   画面右侧的**映射列表**会列出当前所有映射（含总数），点一行就能在画面上
   选中它——多个映射用同一起点叠在一起时，不用在画面上硬点。
   位置重合的条目会标「重合 N」，选中的组件会压在最上层，重叠的其它组件
   自动变暗，便于确认选对了。
4. **导出**：点「导出 JSON」，保存为 `templates/<模板名>.json`
   （工具栏里的「模板名」就是这个文件名），然后在
   `scrcpy_mapping_config.json` 里把 `active_template` 设成同名、`enabled` 设 `true`。
   scrcpy 运行中改了模板会热重载，不用重启。

## 组件与模板字段的对应

| 组件 | 生成的 JSON 字段 |
| --- | --- |
| 单点映射 | `key` + `x`/`y` |
| 滑动映射 | `type: "slide"` + `dx`/`dy`/`duration_ms` |
| 多点同按 | `x`/`y` + `positions: [[x,y], ...]`（含主位置最多 5 个） |
| 开关映射 | `mode: "toggle"`（仅单键触控） |
| 视角拖动 / 视角常驻 | `type: "motion"` + `key: "MOUSE_MOVE"` + `sensitivity` + `hold` |
| 虚拟键 | `virtual: true`（无坐标，只记状态） |
| 组合键 | `key: "lshift+w"` 这类 2~4 成员的组合文法 |
| 鼠标按键 | `key: "MOUSE_LEFT"` / `MOUSE_RIGHT` / `MOUSE_MIDDLE` / `MOUSE_X1` / `MOUSE_X2` |
| 左键锁定 | `key: "MOUSE_LEFT_LOCKED"` |
| 条件映射 | `depends_on` + `depends_state` |

细节以 [`doc/mapping-template-json.md`](../../doc/mapping-template-json.md) 为准，
编辑器里也内置了与加载器一致的明显错误检查（键名重复、组合成员过多、
`toggle` 用在组合/滑动上、依赖条目不存在等），状态栏会实时提示。

## 一个按键映射多个位置

- 用「多点同按」组件：默认 2 个位置，蓝色小圆点可单独拖动，属性面板里
  可以继续「再加一个位置」（最多 5 个），按下这个键时所有位置同时按下。
- 单个「单点映射」也能加位置：选中后用属性面板的「＋ 再加一个位置」。

模板加载时**同名的两个条目会被拒绝**（`duplicate key`），所以一个键要多点
只能用 `positions`，这也是编辑器里多点组件的实现方式。

## 其它

- `Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做、`Ctrl+D` 复制选中组件、`Delete` 删除。
- 属性面板底部「JSON 预览」实时显示将要导出的内容。
- 导入已有模板（工具栏「导入」）会把条目还原成组件，可继续可视化编辑；
  导出的键名原样保留，不做规范化。
